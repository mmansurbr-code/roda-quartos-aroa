# Roda dos quartos – Mansão Aroa

Roda da fortuna para sortear os 10 quartos (13 vagas) entre os 13 participantes, uma pessoa de cada vez.

Abrir: https://mmansurbr-code.github.io/roda-quartos-aroa/

- Digite o nome e clique em **Girar**.
- O sorteio fica salvo no aparelho em que a página está aberta: use um único celular ou computador e passe de mão em mão.
- **Copiar resultado** gera o texto pronto para o WhatsApp.
